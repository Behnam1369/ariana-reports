# Documentation site

Astro Starlight site with the guides, live React and Vue demos, the playground and the generated API reference.

```bash
corepack pnpm --filter docs dev      # generates the API pages, then starts http://localhost:4321
corepack pnpm --filter docs build    # static site in apps/docs/dist
corepack pnpm --filter docs api      # regenerate src/content/docs/api only
```

- The site runs the packages **from source** (see `astro.config.mjs`), so it always documents the code in this repository and needs no package build.
- Live demos are pairs of files, `src/demos/react/<name>.tsx` and `src/demos/vue/<name>.vue`, shown with `<Demo name="<name>" example="<example id>" />`. The code on the page is the file that runs. Sample templates and data are in `src/demos/data.ts`; `packages/core/test/docs-examples.test.ts` checks that they stay valid.
- The playground is `src/pages/playground.astro` with the code in `src/playground/`. Links are shared through the URL hash; nothing is stored on a server.
- `src/content/docs/api` is generated by TypeDoc and is not committed.

## Deploying on Netlify

`netlify.toml` in the repository root has the build command and publish directory. Create a site from the GitHub repository ("Import from Git"); no settings need to be changed. Netlify provides the site URL to the build (`URL`), which Astro uses for the sitemap and canonical links. Pull requests get deploy previews.

Vercel works too: framework preset "Astro", root directory `apps/docs`, install command `corepack enable && corepack pnpm install --frozen-lockfile` run from the repository root ("Include files outside the root directory" on).
