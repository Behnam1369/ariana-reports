# Code of conduct

We want this project to be friendly and useful for everyone, whatever their experience, background or language.

**Expected:** be respectful, assume good intent, give and accept constructive feedback, keep discussion on the technical topic.

**Not acceptable:** harassment, personal attacks, discriminatory language or jokes, publishing other people's private information, spam.

Maintainers may edit or remove comments, issues and pull requests that break these rules, and may block repeat offenders. To report a problem, contact the maintainer through the email address on their GitHub profile. Reports are kept confidential.

This code of conduct applies to the repository, its issue tracker, discussions and the project's website.
